# 🚀 PromptVerse — Next-Gen AI Prompt Marketplace & Hub

**PromptVerse** একটি আধুনিক, ফুল-স্ট্যাক এবং রেসপন্সিভ এআই প্রম্পট শেয়ারিং এবং ম্যানেজমেন্ট প্ল্যাটফর্ম। এখানে ব্যবহারকারীরা বিভিন্ন এআই ইঞ্জিনের (যেমন: Midjourney, ChatGPT, Gemini, Claude) জন্য তৈরি করা প্রম্পট ব্রাউজ করতে, কপি করতে, বুকমার্ক করতে এবং নিজেদের প্রম্পট বিক্রি বা শেয়ার করতে পারেন। প্রজেক্টটিতে প্রিমিয়াম কন্টেন্ট লক মেকানিজম এবং একটি শক্তিশালী অ্যাডমিন মডারেশন অন্তর্ভুক্ত রয়েছে।


## Features

### 👤 User Roles & Dashboard
- **Admin:** সম্পূর্ণ প্ল্যাটফর্মের অ্যানালিটিক্স, অল ইউজার ও পেমেন্ট ট্র্যাকিং এবং রিপোর্টেড প্রম্পট মডারেশন কিউ (Reported Prompts Queue) ম্যানেজমেন্ট।
- **Creator:** প্রম্পট তৈরি, এডিট এবং নিজস্ব প্রম্পট গ্যালারি ট্র্যাকিং সিস্টেম।
- **User:** প্রম্পট ব্রাউজ, প্রম্পট তৈরি, সার্চ, বুকমার্ক, রেটিং এবং কপি করার সুবিধা।

### 🛠️ Core Capabilities
- **Advanced Code-Block Preview:** লাইন নম্বর (Line Numbers) সহ প্রফেশনাল প্রম্পট কন্টেন্ট ডিসপ্লে এবং ওয়ান-ক্লিক কপি-টু-ক্লিপবোর্ড সিস্টেম।
- **Premium Lock Mechanism:** প্রিমিয়াম প্রম্পটের জন্য কন্টেন্ট ব্লার ও লক ওভারলে সিস্টেম, যা প্রো/প্রিমিয়াম প্ল্যান ছাড়া আনলক করা যায় না।
- **Community Moderation:** প্রম্পটগুলোর কোয়ালিটি বজায় রাখতে কমিউনিটি ফ্ল্যাগ/রিপোর্ট মেকানিজম এবং অ্যাডমিনদের জন্য ইনস্ট্যান্ট অ্যাকশন (Warn, Dismiss, Remove) ড্যাশবোর্ড।
- **Responsive Navigation:** ডেস্কটপের জন্য স্থায়ী সাইডবার এবং মোবাইলের জন্য গ্লাস-মর্ফিজম ব্লার ইফেক্টসহ ফ্লোটিং ড্রয়ার (Slide-in Menu) নেভিগেশন।

## 🛠️ Tech Stack

- **Frontend:** Next.js (App Router), React, Tailwind CSS, HeroUI (NextUI)
- **Database:** MongoDB (Atlas)
- **Authentication:** Better Auth (authClient)
- **Icons & UI Utilities:** Gravity UI Icons, Lucide React, Sonner (Toasts)
